# Governance

SecScanMonitor is maintained as a security-first proprietary source-visible publication. The public repository is the reviewable platform edition; private operational material, client engagements, evidence, ledgers, and release receipts remain outside it.

The project’s non-negotiable principles are advisory-first operation, no secret handling, no false confidence, evidence discipline, deterministic comparison, source-grounded research, contract-required engagements, localhost-first services, and charter stability.

Changes to authority boundaries, the finding lifecycle, public/private separation, or security workflows require maintainer review and explicit tests. A documentation change cannot silently authorize a runtime capability.

Maintainers may decline changes that broaden scope without evidence, weaken refusal behavior, add unreviewed network access, or make a `NOT_VALIDATED` integration appear qualified.
